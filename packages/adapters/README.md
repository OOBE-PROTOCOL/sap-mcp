# SAP MCP adapters

Solana connection and public key adapter utilities.

This is an internal workspace package. It is not published independently.
The public API surface is re-exported through the root `@oobe-protocol-labs/sap-mcp-server` package.

## Boundary

Source of truth: `packages/adapters/src/`
Compatibility wrapper: `src/adapters/solana/` (thin re-exports)
